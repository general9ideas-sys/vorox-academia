Full Stack Development

Programa profesional para convertirte en desarrollador Full Stack: desde HTML, CSS y JavaScript hasta React, Node.js, bases de datos, autenticación y despliegue en producción.

Duración: 8 meses Horas: 1.280 h Modalidad: Online en vivo Nivel: Principiante a Intermedio
Ver las 44 clases Nivelación gratis Quiero información

¿Qué vas a aprender?

  • Construir interfaces modernas con HTML, CSS, Flexbox, Grid y responsive design
  • Programar en JavaScript ES6+ y manipular el DOM con buenas prácticas
  • Desarrollar SPAs con React: componentes, hooks, routing y consumo de APIs
  • Crear backends con Node.js y Express: REST, validación y arquitectura por capas
  • Diseñar y consultar bases de datos SQL (PostgreSQL) y NoSQL (MongoDB)
  • Implementar autenticación JWT, testing y despliegue con Docker y cloud
  • Entregar un proyecto final de portfolio como Full Stack Developer
